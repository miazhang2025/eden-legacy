# 性能记录（spec §12.3）

每加一个效果，都要在这里记一行实测开销。没有实测数据的效果不算完成。

**怎么测**：look dev 面板 → 工具 → 性能 → 测开销（开关 A/B）→ 选效果的 `enabled` 开关 → 测量。
结果也会打印在控制台（`[lookdev][perf] ...`）。

注意：浏览器帧率被显示器刷新率封顶，效果开销小于余量时 Δ 会接近 0。
要看真实开销，请在性能吃紧的设备上测（或把 pixelRatio 调高制造压力），必要时配合 DevTools Performance 面板。
